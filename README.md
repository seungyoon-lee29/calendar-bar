# Calendar Bar

macOS 14 이상에서 쓰는 작은 메뉴 막대 캘린더입니다. 오늘 날짜 아이콘을 눌러 월 달력과 선택한 날짜의 일정을 확인합니다. SwiftUI/AppKit과 시스템 EventKit을 사용합니다.

## 빌드 및 실행

Swift 도구가 설치된 macOS에서 다음을 실행합니다.

```sh
python3 scripts/verify.py
open build/CalendarBar.app
```

개발 테스트는 `python3 scripts/run.py 300 swift test --jobs 2`로 실행합니다. 실행 파일을 직접 실행하는 대신 생성된 앱 번들을 사용하세요.

## 캘린더 연결

1. 시스템 설정 → 인터넷 계정에서 Google 계정 등을 추가하고 **캘린더** 동기화를 켭니다. Apple 캘린더 앱에서 일정이 보이는지 확인합니다.
2. Calendar Bar의 **캘린더 연결**을 누릅니다. macOS에서는 일정 조회에도 **전체 접근** 권한을 요청합니다. 앱은 일정을 읽기만 하며 추가·수정·삭제 기능을 제공하지 않습니다.
3. 톱니바퀴 설정에서 표시할 캘린더를 선택합니다. 이름 아래 계정/소스를 확인할 수 있습니다.

거부한 권한은 앱의 **시스템 설정 열기**에서 변경합니다. 캘린더가 없다면 인터넷 계정의 동기화를 확인하세요. 연결·선택·오류 상태는 정상 조회 후의 `일정 없음`과 구별됩니다. Google 자체 OAuth 서버나 앱 전용 토큰은 사용하지 않습니다.

## 사용

- 이전/다음 버튼 또는 달력 영역의 좌우 드래그로 월을 이동합니다. 왼쪽은 다음 달, 오른쪽은 이전 달입니다. 40pt를 넘고 가로 이동이 세로보다 커야 합니다.
- 날짜를 클릭하면 해당 날짜 일정이 표시됩니다. 오늘은 파란 원, 다른 선택 날짜는 테두리로 표시합니다. 점은 그 날짜에 일정이 있는 캘린더를 나타냅니다.
- `오늘` 또는 팝오버를 다시 열면 오늘로 돌아갑니다. 자정/시간대 갱신은 열린 상태에서 보고 있던 월을 유지합니다.
- 설정에서 로그인 시 실행 상태를 확인·변경하고 앱을 종료할 수 있습니다. 최초 일반 실행에서는 로그인 항목 등록을 시도하며, 운영체제 승인이 필요할 수 있습니다.
- `--smoke` 실행은 자동 로그인 항목 등록을 건너뜁니다. 실제 캘린더 연결은 사용자 버튼 동작으로만 요청합니다. 테스트용 예시 일정은 제품에 포함하지 않습니다.
