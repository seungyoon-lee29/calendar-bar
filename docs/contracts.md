# 시스템 연동 계약

외부 HTTP API는 없다. EventKit의 fullAccess만 일정 조회 허용으로 간주한다. notDetermined는 미요청, denied/writeOnly는 연결 거절 상태, restricted는 제한 상태다. 권한 부족을 정상 0건 결과로 변환하지 않는다.

조회는 표시하는 주 격자의 시작부터 마지막 날 다음 날짜 시작 직전까지와 선택 캘린더 ID 집합을 받는다. 빈 선택으로 전체 캘린더를 조회하지 않는다. 캘린더는 시스템 ID·이름·출처·색을 전달하고, 일정은 캘린더 ID·이벤트 ID·발생 시작·종료·제목·종일 여부를 전달한다. 동일 이벤트 ID의 반복 발생분을 합치지 않는다.

화면 상태는 연결 필요, 캘린더 없음, 선택 필요, 로딩, 조회 성공, 조회 실패로 구별한다. 성공은 0건을 포함한다. EventKit 변경 통지와 잠자기 복귀에 저장소를 다시 읽고 이전 객체를 재사용하지 않는다. 시스템 동기화 지연은 앱 외부 계약이다.

ServiceManagement의 enabled, notRegistered, requiresApproval, notFound를 각각 켜짐, 꺼짐, 승인 필요, 실패로 표시한다. 등록 요청을 보냈다는 사실만으로 켜짐이라 표시하지 않는다.
