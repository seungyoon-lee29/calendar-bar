# 구현 현황

월간 달력·오늘 강조·날짜 선택·월 이동과 드래그, 선택일 목록, 읽기 전용 시스템 캘린더 연결, 표시 캘린더 선택, 로그인 항목 관리가 코드에 구현되어 있다. 전체 25개 테스트와 release 번들 빌드·서명 검증은 통과했다.

실제 메뉴막대 렌더·바깥 클릭·드래그 확인은 자동화 도구 접근 오류로 미검증이다. 실제 구글 계정 일정 대조·권한 흐름·재로그인 실행도 미검증이다. 이 항목을 완료로 간주하지 않는다. 코드 최종 검토와 사용자 확인이 남아 있다.

확정된 후속 기능은 없다. 현재 제품 범위는 개인 맥의 날짜·일정 확인이며 일정 편집·알림·공휴일 전용 데이터·음력·다른 운영체제·공개 배포는 포함하지 않는다.
