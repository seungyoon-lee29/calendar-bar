# 앱 종료 뒤에도 남는 로컬 알림

일정 관리는 기존 캘린더에서 계속하면서 사용자가 선택한 발생분만 여러 번 알릴 필요가 있다. 메뉴막대 앱이 종료된 동안에도 이미 정한 알림은 전달되어야 한다.

앱이 현재 일정을 읽어 UserNotifications에 가까운 알림을 미리 예약한다. 별도 상주 도우미·서버·원본 일정 알림 변경은 사용하지 않는다. 상주 도우미는 변경 감지를 늘릴 수 있지만 별도 프로세스 수명·권한·배포가 필요하고, 서버는 개인 일정 전송과 계정 관리가 추가된다. 원본 알림 수정은 읽기 전용 도구의 경계를 바꾼다.

따라서 앱을 완전히 닫으면 미리 예약한 알림은 전달되지만 그 뒤 발생한 변경·삭제·권한 회수는 즉시 반영할 수 없다. 예전 제목이 남을 수 있다는 제한을 사용자가 수용했다. 가까운 예약부터 제한 수를 채우고 실행 중 보충하며, 다음 실행 때 현재 권한·선택·일정을 다시 확인한다. 장기간 종료 후에는 앱 재실행이 필요하다.
