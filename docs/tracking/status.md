월간 달력·오늘 강조·날짜 선택·월 이동과 드래그, 선택일 목록, 읽기 전용 시스템 캘린더 연결, 표시 캘린더 선택, 로그인 항목 관리가 코드에 구현되어 있다. 임시 진단 제거를 통합한 `185d998`에서 메인 검증자가 프로젝트 루트 전체 검증을 실행했고, `.dryforge/resume-integrated-verify.log`에서 Swift 114개·Python 9개 통과, release 번들·서명 검증과 INTEGRATED_EXIT 0을 확인했다. 이전 통합 로그의 Swift 116개에서 임시 진단 전용 테스트 2개가 제거된 수치이며 실제 알림 클릭 성공을 뜻하지 않는다.

실제 메뉴막대 기준 팝오버 렌더, 좌우 드래그·같은 일자 유지·짧은 드래그 제외, Escape 닫기와 재열기 오늘 복귀를 확인했다. 이전 빌드에서 Google 기본 캘린더 9/29 일정 2개의 제목·시간을 읽었고 Apple 캘린더의 동일 날짜와 일치함을 확인했다. 재실행 시 권한·캘린더 선택 복원과 실제 로그인 실행 등록 enabled까지 확인했다. 바깥 클릭으로 닫히는 동작은 사용자가 최종 확인했다. 실제 재로그인 확인은 수행하지 않았다.
