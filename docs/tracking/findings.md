# 미해결 확인 사항

- 메뉴막대 앱 UI 자동 확인 불가: bundle ID와 앱 경로로 접근하면 컴퓨터 사용 도구가 timeoutReached를 반환한다. Finder 접근성은 동작했다. 시작 콜백과 프로세스 생존만으로 렌더·바깥 클릭·드래그 성공을 판단할 수 없다. 사용자에게 아이콘/달력 표시 여부를 요청했고 응답 대기 중이다.
- 실제 캘린더 연동과 로그인 실행: 현재 테스트는 가짜 저장소와 자동 등록을 건너뛴 실행을 사용했다. 사용자 캘린더 권한 허용과 실제 계정 동기화 대조, 재로그인 확인이 필요하므로 아직 성공이라고 보고할 수 없다. 앱이 사용자 일정을 수정하거나 검증을 위해 로그아웃하지 않는다.
