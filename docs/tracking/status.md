# 구현 현황

월간 달력·오늘 강조·날짜 선택·월 이동과 드래그, 선택일 목록, 읽기 전용 시스템 캘린더 연결, 표시 캘린더 선택, 로그인 항목 관리가 코드에 구현되어 있다. 전체 32개 Swift 테스트와 3개 프로세스 정리 테스트와 release 번들 빌드·서명 검증은 통과했다.

실제 메뉴막대 기준 팝오버 렌더, 좌우 드래그·같은 일자 유지·짧은 드래그 제외, Escape 닫기와 재열기 오늘 복귀를 확인했다. 이전 빌드에서 Google 기본 캘린더 9/29 일정 2개의 제목·시간을 읽었고 Apple 캘린더의 동일 날짜와 일치함을 확인했다. 재실행 시 권한·캘린더 선택 복원과 실제 로그인 실행 등록 enabled까지 확인했다. 바깥 클릭의 최종 사용자 확인과 실제 재로그인 확인은 남아 있다.

확정된 후속 기능은 없다. 현재 제품 범위는 개인 맥의 날짜·일정 확인이며 일정 편집·알림·공휴일 전용 데이터·음력·다른 운영체제·공개 배포는 포함하지 않는다.
